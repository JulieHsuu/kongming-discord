# 文件配圖與顧問功能

## 配圖

在案件頻道說：`@孔明 請在訪綱加入企業高階主管喝咖啡的情境示意圖。`

會實際呼叫 LiteLLM `/images/generations`，交付 PNG 與內嵌圖片的 Word，保留原版。需設定 `KM_MODEL_IMAGE`；目前已用 `gpt-image-1` 實測。虛構人物會標示情境示意。產圖失敗不交付空配圖版。圖片生成會有模型費用，機密案件禁止外部產圖。

舊文件不會自行改變，請下載新的「配圖版」。使用「訪綱／訪前」指定目標，可避免把圖片加到企業研究文件。舊版没有版本紀錄時，依已保存的訪綱資料重建配圖文件；本次既有大成檔案已另行補圖並保留原版。

## 讀取檔案及證據

- XLSX：工作表、儲存格、公式及快取結果；不重新計算公式，不讀嵌入圖片或巨集。非空儲存格上限 20,000。
- PPTX：投影片文字及頁次；圖片中的文字、講者備註與圖表資料尚未抽取。
- PDF：逐頁文字；無文字的頁面才渲染圖片做 OCR。掃描頁上限 `KM_OCR_MAX_PAGES=20`，OCR 人名、數字需人工核對。
- DOCX：本文段落位置；尚未讀頁首頁尾與內嵌圖片文字。
- `/孔明 證據`：下載案件已建檔附件的原始文字位置、逐字稿時間碼與網路研究來源；可加關鍵字。新版啟用前的附件不會補回原文，也不是每一筆模型判斷都已逐項綁定原句。

檔案全文超過單次建檔 24,000 字／訪談整理 36,000 字時會要求分檔，不會靜默截掉後半段。

## 局部修改及版本

`@孔明 只修改簡報第 2 頁，把標題改為……。`

`@孔明 只改 Word 第 5 段，把……改為……。`

會改指定文字段落，保留其他 XML、圖片與樣式，附比較 TXT。指定頁／段落的範圍會由程式檢查，模型修改範圍不符就拒絕交付。新增／刪除整頁、表格布局及圖表結構修改尚未支援。

`/孔明 文件版本` 列出新版啟用後的文件；指定版本編號可以重新下載原版。舊文件需重新產出才有完整版本索引。局部修改必須由顧問核對排版，文字增長可能改變分頁。

## 負責人與私密頻道

新案件記錄建立／首次操作的負責人。在 Discord 先拒絕 `@everyone` 查看頻道，再由負責人或有「管理伺服器」權限的人執行：

`/孔明 案件權限 模式:限制在此私密頻道`

工具限制案件只在此頻道使用，排除跨案件清單與提醒，不提供公開下載連結；同事的查看／發言權限由 Discord 頻道身分組管理。這不是另建一套應用程式內的讀者／編輯者權限。舊頻道已發出的訊息、已下載的副本或先前快取不會撤回，需在 Discord 處理。改回「團隊共用」會恢復共用。

## 交接與下一步

- `/孔明 交接`：Word 說明及 ZIP，含已知資料、定案、待確認、待辦、下一步、原始來源文字與各類最新檔案；過期檔案不包含。
  案件概要使用欄位／來源表格，不輸出模型內部工作偏好。「待核准變更」與資料缺漏、預算明細、POC 待釐清事項分開列出。已有訪綱初稿的製作待辦會顯示為更新與覆核，原待辦狀態不自動更改。
  修改版及配圖版沿著原版版本關係挑選，每類檔案只打包目前有效版本；舊交接包與虛構案件的舊網路研究不打包。版本索引 JSON 分為 `current` 和 `history`，歷史僅供追溯。時間顯示為臺北時間。
- `/孔明 下一步`：依現有資料列出缺漏、訪談、預算與 POC 前置事項；這是準備檢查，不代表資格或提案成功保證。

## 驗證

`node test/consultant-run.js`：圖片內嵌、圖片 API 失敗、局部修改保留原文及全部其他部件、Office 讀取、掃描 PDF 渲染 OCR、交接、頻道限制、版本下載、附件選擇、虛構資料隔離與交接內容共 39 項檢查。

`node scripts/check-image-docx.js`：實際呼叫圖片模型，產出測試 PNG 及含圖 Word，會產生模型費用。日常測試不需執行這個實際呼叫。
