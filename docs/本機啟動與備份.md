# Windows 本機啟動與備份

已設定 Windows 工作排程器，使用目前登入帳號的一般權限，不保存密碼。

| 排程 | 執行時間 | 行為 |
| --- | --- | --- |
| Kongming-AutoStart | 登入 Windows 後；每 5 分鐘檢查 | 程序不在時啟動；已在執行就略過 |
| Kongming-DailyBackup | 每天台灣時間 03:00 | 備份 state，解壓前校驗每個檔案，保留最近 14 天 |

電腦必須開機並登入；關機或休眠時 Bot 無法服務，備份不會執行。錯過的備份由工作排程器於可執行時補跑。若需 24 小時服務，應部署到持續開機的伺服器。

## 平常使用

登入後到 Discord 看孔明是否上線即可。工作排程器可搜尋以上兩個排程，查看執行時間與結果。

備份位於 `D:\孔明\kongming-discord\backups`，檔名 `kongming-日期-時間.zip`。備份包含案件、文件、對話、設定狀態及工作紀錄；不包含 `.env` 金鑰、程式套件與執行日誌。這是同一台電腦的備份，無法防止 D 槽故障；可另外把 ZIP 複製到外接硬碟。

這是運作中的逐檔快照，並非整個系統在同一瞬間的交易快照。

## 手動執行

在 PowerShell 執行：

```powershell
cd D:\孔明\kongming-discord
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\start-local.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\backup-local.ps1
```

## 驗證還原

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\verify-backup.ps1
```

將最新備份解壓到 backups 下獨立的 restore-check 資料夾，驗證 SHA-256 與 JSON 格式，不覆蓋正式資料。驗證資料夾可檢視檔案。

真正還原前需暫停 Kongming-AutoStart、停止 Bot，另外備份目前 state，再以驗證過的備份 state 取代正式 state，最後啟動並重新啟用排程。需要還原時可以交給 Codex 操作；不要在 Bot 執行中覆蓋 state。

## 暫停孔明

先在工作排程器停用 Kongming-AutoStart，再停止 Bot 程序，避免五分鐘後被自動啟動。恢復時重新啟用該排程並按「執行」。
